# Das-security

这是一个静态宣传页，入口为 `index.html`，配图等资源与页面文件一同存放。

## 本地预览

在仓库目录中直接用浏览器打开 `index.html`；也可运行 `python3 -m http.server 8000`，再访问 `http://localhost:8000`。

## 更新与发布

按需编辑 `index.html` 及其静态资源，先在本地浏览器检查，再将页面文件和所需资源发布到静态网站托管环境。发布流程及目标环境由项目负责人维护。

## 上线前核验

上线前请负责人核验备案信息、案例真实性及相关内容的使用授权。页面不得使用虚构备案编号；需展示备案信息时，应由负责人确认真实、准确的编号后再更新。
